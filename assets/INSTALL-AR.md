# اختبار باتش تخطي مشاهد Ghost of Yotei

هذا مثبّت تعريف باتش تجريبي، وليس HEN ولا باتش تسريع. خاص بـ PPSA26344 / 01.008.000. لم يُختبر على PS5.

1. فعّل 331HEN الحالي وشغّل مثبّت SkipPatch مرة واحدة. انتظر إشعار نجاح تثبيت XML؛ الإشعار لا يعني تطبيقه على اللعبة.
2. أعد تشغيل الجهاز وفعّل نفس 331HEN الأساسي لتحديث قائمة التعريفات المخزنة في الذاكرة.
3. قبل تشغيل اللعبة افتح 331HEN Tools → Game Tools → Game Patches، واختر Ghost of Yotei ثم Enable existing cutscene skip permission (EXPERIMENTAL) وفعّله.
4. شغّل اللعبة، وجرّب خيار/زر التخطي المعتاد الذي توفره اللعبة في مشهد عادي. لا توجد اختصارات R1 جديدة ولا سرعة x2/x4. بعض المشاهد التي يرفضها منطق اللعبة قد تبقى دون تخطي.
5. تحقق من العودة للتحكم واستمرار هدف المهمة بعد المشهد. عند أي خلل عطّل الباتش ثم أغلق اللعبة وأعد تشغيلها؛ تعطيله في القائمة يحفظ OFF، ولا يرجع بايتات الجلسة الحالية فورًا.

يُفضّل استخدام خانة حفظ منفصلة للاختبار حتى لا تعتمد تقدم القصة على تعديل غير مختبر. المثبّت لا يعدّل الحفظ، لكن تخطي مشهد أثناء اللعب يمكن أن يغيّر تقدم الجلسة الذي تحفظه اللعبة.

إذا حدثت مجموعة الباتشات لاحقًا قد تختفي هذه الإضافة المحلية؛ شغّل المثبّت مجددًا وأعد تفعيل HEN بعد ريستارت. لا يلزم تبديل الكستف. لا تعيد تشغيل HEN آخر في الجلسة نفسها.

التركيب اليدوي: ضع ملف XML في /data/331HEN/patches/xml/<القيمة ذات 64 خانة الموجودة في config/current>/؛ إذا لا يوجد config/current استخدم /data/331HEN/patches/xml/. لا تغيّر current ولا تحذف المجموعة. المثبّت يقوم باختيار المسار تلقائيًا.
