# تثبيت 331HEN Autoloader

1. فعّل الجلبريك الحالي بالطريقة المعتادة.
2. شغّل ملف المثبّت من Payload Manager إذا توفر فيه الملف، أو أرسله عبر ELF Loader الشبكي الذي تستخدمه. وجود رابط تحميل هنا لا يضيفه تلقائيًا إلى مصدر Payload Manager.
3. عند ظهور اختيار Poops أو Relapse اختر السلسلة التي تستخدمها وتعمل عندك حاليًا. انتظر تأكيد نجاح التخزين والتثبيت.
4. أعد تشغيل PS5 مرة واحدة وافتح 331HEN Autoloader من الشاشة الرئيسية.
5. إذا لا يوجد autoload.txt يفتح Payload Manager. لضبط تحميل 331HEN تلقائيًا استخدم إعداد Autoload في Payload Manager وحدد النسخة الأساسية مرة واحدة فقط، وألغِ تحميل Preview أو HEN آخر أو كستف مستقل إن كان مفعّلًا.

التثبيت يحدّث اختصار WebKit Autoloader الموجود لأن معرّفه نفسه WKAL00001. لا يحذف ملفات 331HEN أو الچيتات أو الباتشات. لا تحتاج كمبيوتر أو DNS خارجي بعد نجاح التخزين المحلي. كل ريستارت يحتاج فتح الاختصار؛ هذا ليس تشغيلًا تلقائيًا لحظة إقلاع الجهاز.

المثبّت الجديد لم يُختبر على PS5. إذا حدث خطأ أثناء التخزين، احتفظ برسالته؛ لا تمسح بيانات المتصفح تلقائيًا دون مراجعة.
